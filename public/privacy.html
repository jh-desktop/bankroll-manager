개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 05월 27일

📋 개요

뱅크롤 관리 앱(이하 "서비스")은 사용자의 개인정보를 소중히 여깁니다. 본 방침은 어떤 정보를 수집하고, 어떻게 이용하며, 어떻게 보호하는지를 설명합니다.

서비스를 이용함으로써 본 방침에 동의하는 것으로 간주됩니다.

📦 수집하는 정보

서비스는 Google 로그인을 통해 다음 정보를 수집합니다.

항목수집 시점목적
이름 (표시 이름)로그인 시서비스 내 사용자 식별
이메일 주소로그인 시계정 식별 및 중복 방지
프로필 사진로그인 시서비스 내 아바타 표시
FCM 토큰알림 허용 시푸시 알림 발송
입력 기록 데이터사용 중서비스 핵심 기능 제공

위치 정보, 연락처, 결제 정보 등은 수집하지 않습니다.

🎯 정보 이용 목적

  • 서비스 내 계정 생성 및 사용자 식별
  • 워크스페이스 멤버 표시 및 기록 관리
  • 사용자가 허용한 경우 푸시 알림 발송
  • 서비스 이용 통계 및 오류 개선

수집된 정보는 제3자 광고, 마케팅 목적으로 사용되지 않습니다.

☁️ 데이터 저장 및 보안

모든 데이터는 Google Firebase (Firestore, Cloud Messaging)를 통해 Google Cloud 서버에 안전하게 저장됩니다. 데이터 전송은 HTTPS/TLS로 암호화됩니다.

Firebase의 보안 정책에 대한 자세한 내용은 firebase.google.com/support/privacy 에서 확인하실 수 있습니다.

🔗 제3자 서비스

서비스는 다음 제3자 서비스를 이용합니다.

  • Google Firebase — 인증, 데이터베이스, 푸시 알림
  • Google Sign-In — 소셜 로그인
  • Vercel — 앱 호스팅 및 API 서버

위 서비스들은 각자의 개인정보처리방침을 따릅니다.

🧹 데이터 보유 및 삭제

  • 서비스 탈퇴 또는 워크스페이스 삭제 시 해당 데이터가 즉시 삭제됩니다.
  • FCM 토큰은 알림 비허용 또는 만료 시 자동 삭제됩니다.
  • 데이터 삭제를 원하시면 아래 이메일로 요청하실 수 있습니다.

👤 사용자 권리

사용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 본인 데이터 열람 및 수정 요청
  • 데이터 삭제 요청 (계정 탈퇴)
  • 푸시 알림 수신 거부 (기기 설정에서 변경 가능)

🔔 어린이 개인정보
